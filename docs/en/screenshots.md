# Screenshots of the native drawing

All screenshots taken during development live here (in `docs/screenshots/`), separated by date in a `AAAA-MM-DD/` subfolder (YYYY-MM-DD) and named `AAAA-MM-DD_descricao.png` (`descricao` = description; e.g. `2026-10-16/2026-10-16_widescreen_luta.png`). They serve as a visual history
of what improved (or broke) with each change. They show the game's art rendered by the native layer: if the project is ever
opened to the public, review this folder first (rule 1 of [CLAUDE.md](CLAUDE.md): no game file in the repo).
