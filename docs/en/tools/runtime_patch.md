# Runtime patch (PS2Recomp)

[`wotm-runtime.patch`](../../../tools/runtime_patch/wotm-runtime.patch): the **seams** in `ran-j/PS2Recomp` (base commit `2c5fbb9`) that the game needs: CMake (`WOTM_NATIVE_DIR`, mandatory; since 2026-10-19 two executables from the same game objects, `wotm` without emulated GS/VU1/VIF0/VIF1 or EE timers and with a single-thread scheduler (`Kernel/EeSchedulerGame.cpp`, a file added by the patch), with `PS2X_HW_EMU=0` and without the IOP, neither interpreter nor RAM (`ps2_iop_game`, with `ps2xIOP/src/iop_subsystem_host.cpp`, a file added by the patch; native movies by default), and the test `ps2EntryRunner`: compile `--target ps2EntryRunner wotm`; [BOUNDARY.md](../steps/BOUNDARY.md) (`docs/passos/FRONTEIRA.md`), steps 5 to 10), `main.cpp` (hooks and `--vu1cmp`), GS SDK stubs (`Kernel/Stubs/GS.cpp`), taps on VIF1/VU1/memory for the VU1 vs native check, keyboard, host profiling (`PS2X_HOSTPROF`), IOP batching (`PS2X_IOP_BATCH`, 60 vsync/s in the level), measurements and the 64 MB RAM with the game seeing 32 (`PS2_RAM_SIZE`/`PS2_GUEST_RAM_SIZE` in `ps2_memory.h`, stack and heap in `System.cpp` and `ps2_runtime.cpp`; [NATIVE.md](../steps/NATIVE.md) (`NATIVO.md`), "64 MB RAM and loading above 32 MB").

The game-specific code that runs inside the runtime **is not in the patch**: it lives in `native/runtime/` in this repo (`wotm_live.inc`, `wotm_scene.inc`, `wotm_snd.inc`, `wotm_vu1check.inc`, `wotm_overrides.cpp`, `wotm_vu0_native.cpp/.h`) and the fork's CMake includes and compiles it from `-DWOTM_NATIVE_DIR=<repo>/native` (see [NATIVE.md](../steps/NATIVE.md) (`docs/passos/NATIVO.md`), "Onde mora o código do runtime" (where the runtime code lives)). `wotm_vu0_native.gen.inc` (translated VU0 microcode, game code) is generated by `build_runtime.ps1` into `<build>\wotm_gen`.

Left out: `ps2xRuntime/src/runner/register_functions.cpp` (function registry generated from the game: game code, it does not go into the repo). Generate it with PS2Recomp from your ELF.

Applying: `git apply --whitespace=nowarn tools/runtime_patch/wotm-runtime.patch` inside the PS2Recomp clone. Regenerating (in the clone, with the same file list as the current patch): `git diff HEAD -- <arquivos>` (files); never include the ones from `native/runtime/`.

[`wotm-fmv.patch`](../../../tools/runtime_patch/wotm-fmv.patch): native movies (`PS2X_FMV=1`, `native/wotm_fmv.hpp`). Base: branch `wotm` of the fork (`yanm1103/PS2Recomp`, 79a7c7e, the submodule). It touches `wotm_live.inc` (hooks and `wotmFmvInstall`/`wotmFmvPresent`), `ps2_runtime.cpp` (call at presentation) and `main.cpp` (installation). It needs `-DWOTM_NATIVE_DIR=<WoTM>/native` and FFmpeg (`PS2X_ENABLE_FFMPEG`, default on Windows); without them, `PS2X_FMV` only warns. Applying: `git apply --whitespace=nowarn tools/runtime_patch/wotm-fmv.patch` inside `third_party/PS2Recomp`.
