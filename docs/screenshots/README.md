# Capturas de tela do desenho nativo

Todas as capturas feitas durante o desenvolvimento ficam aqui, separadas por data numa subpasta `AAAA-MM-DD/` e nomeadas `AAAA-MM-DD_descricao.png` (ex.: `2026-10-16/2026-10-16_widescreen_luta.png`). Servem de histórico visual
do que melhorou (ou quebrou) a cada mudança. Elas mostram a arte do jogo renderizada pela camada nativa: se o projeto for
aberto ao público, vale rever essa pasta antes (regra 1 do `CLAUDE.md`: nenhum arquivo do jogo no repo).
